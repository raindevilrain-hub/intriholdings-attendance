인트리홀딩스 출근 자동 체크 - 설치/사용 안내

[설치 - 1분]  파일은 이거 하나면 됩니다.
1. "인트리홀딩스_출근자동체크_설치.exe" 를 회사 PC로 복사합니다.
2. 더블클릭 -> "설치할까요?" 에서 [예]
3. 이어서 열리는 창에 하이웍스 아이디/비밀번호를 한 번만 입력합니다.
   * 반드시 사무실 네트워크(유선 랜/사내 Wi-Fi)에서 진행하세요.
     이때 접속한 네트워크가 "회사망"으로 등록되고, 다른 네트워크
     (집, 카페, 휴대폰 테더링 등)에서는 자동 출퇴근이 동작하지 않습니다.
   * 아이디는 90807867 처럼 앞부분만 써도, 이메일 전체를 써도 됩니다.
   * 한 번 등록하면 계속 저장되어, 다음부터는 입력할 필요가 없습니다.
     비밀번호는 이 PC의 내 Windows 계정으로만 풀 수 있게 암호화되어 저장됩니다.

[평소 사용 - 아무것도 안 하셔도 됩니다]
- Windows에 로그인하면 자동으로 실행되어 하이웍스 출근 체크를 합니다
  (화면에 아무것도 안 뜹니다). 부팅 직후 네트워크가 늦게 잡혀도 최대 5분
  기다렸다가 체크하고, 끝내 실패했을 때만 안내창이 뜹니다.
- 바빠서 하이웍스에 직접 먼저 출근 체크를 하신 경우, "오늘 출근 체크를
  이미 하셨나요?" 창이 한 번 뜹니다. [예]를 누르면 그날은 더 묻지 않습니다
  (응답이 없어도 20초 뒤 자동으로 넘어가고, 그날 또 묻지 않습니다).
  매번 묻는 게 번거로우면 트레이 아이콘 우클릭 -> "이미 출근했으면 묻지 않기"를
  체크하세요 (상태 창 아래쪽 체크박스로도 켤 수 있습니다). 켜 두면 하이웍스가
  이미 출근 상태일 때 묻지 않고 오늘 출근 완료로 기록합니다.
- 컴퓨터를 종료할 때 그날 퇴근 체크가 안 되어 있으면(시간과 무관하게, 조퇴도 포함),
  종료를 한 번 멈추고 "퇴근 체크를 먼저 해주세요" 창이 뜹니다.
  (시스템 종료·재시작·로그오프 모두 동일합니다.)
  * [예]  : 하이웍스 퇴근 체크를 하고 컴퓨터를 종료합니다.
    체크가 끝나면 "퇴근 체크 완료" 안내가 잠깐 떴다가 자동으로 꺼지며 종료됩니다.
  * [아니오]: 이번 종료는 취소됩니다. 퇴근 체크 후 다시 종료해 주세요.
  * 20초간 응답이 없으면(자리 비움) 이번 종료는 그대로 진행됩니다.
  * [아니오]를 누르거나 응답 없이 지나간 뒤에도, 퇴근 체크가 안 된 채로 다시
    종료를 누르면 그때마다 다시 물어봅니다 (한 번 넘겼다고 끝나지 않습니다).
  * 이미 퇴근 체크가 되어 있거나 회사망이 아니면 묻지 않고 바로 종료합니다.

[트레이 아이콘]
- 실행 중에는 작업표시줄 오른쪽 알림영역(^ 버튼 안쪽)에 아이콘이 있습니다.
  * 아이콘에 마우스를 올리면 오늘 출근/퇴근 상태가 보입니다.
  * 우클릭 -> 지금 출근 체크 / 지금 퇴근 체크 / 이미 출근했으면 묻지 않기 /
    상태 창 열기 / 업데이트 확인 / 종료
  * 트레이에서 "종료"한 뒤에도 바탕화면 아이콘으로 프로그램을 다시 열면 자동 출퇴근
    기능이 같이 다시 켜집니다.
  * 더블클릭하면 상태 창이 열립니다.
  * 항상 보이게 하려면 아이콘을 작업표시줄로 끌어다 놓으세요.

[프로그램 창]
- 바탕화면 "인트리홀딩스 출근 자동 체크" 아이콘을 실행하면
  * 로그인이 되어 있으면 "로그인이 되어 있네요 :)" 를 보여주고 잠시 뒤
    자동으로 창이 최소화됩니다.
  * 화면 아래쪽 [지금 출근 체크] / [지금 퇴근 체크] 버튼으로
    언제든 직접 체크할 수 있습니다.
  * 그 위의 체크박스(출근 체크 / 퇴근 체크)와 [선택 실행] 버튼으로 둘 중
    원하는 것만, 또는 둘 다 한 번에 실행할 수도 있습니다.

[업데이트]
- 자동 업데이트: 프로그램이 켜질 때마다(Windows 로그인, 컴퓨터 켜기, 프로그램 다시 실행)
  새 버전이 있는지 확인해서 있으면 자동으로 내려받아 설치합니다. 켜 둔 채로 있어도
  6시간마다 다시 확인합니다. 설치 중 화면이 잠깐 닫혔다가 다시 시작될 수 있습니다.
  (출근/퇴근 체크가 진행 중이면 끝난 뒤로 미룹니다)
- 직접 확인: 트레이 아이콘 우클릭 -> "업데이트 확인", 또는 상태 창 아래 "업데이트 확인"
  버튼. 현재 버전은 상태 창 아래쪽(v1.x.x)에 표시됩니다.
- 설치 파일을 다시 더블클릭해도 덮어써서 업데이트됩니다.
  (저장된 로그인/회사망 설정은 그대로 유지됩니다)

[제거]
- Windows 설정 > 앱 > 설치된 앱 > "인트리홀딩스 출근 자동 체크" > 제거
  (또는 트레이 아이콘 우클릭 후 종료해도 그날은 동작하지 않습니다)

[참고]
- 자동화 브라우저는 Windows 기본 Edge를 사용합니다. 별도 설치가 필요 없습니다.
- 회사 인터넷의 공인 IP가 바뀌면(회선 교체 등) 자동 출퇴근이 멈춥니다.
  관리자에게 문의해 주세요.
- 오류가 나면 %APPDATA%\IntriHoldingsAttendance\debug 폴더의 캡처 이미지와
  같은 폴더의 activity.log(종료·출근 판단 기록)를 관리자에게 전달해 주세요.
- 서명되지 않은 프로그램이라 처음 실행할 때 Windows "PC 보호" 창이 뜰 수 있습니다.
  [추가 정보] -> [실행]을 눌러 주세요.
- 이 PC의 시작프로그램에 예전 출근 스크립트(hiworks_checkin.ahk)가 있다면
  중복 방지를 위해 제거해 주세요.
